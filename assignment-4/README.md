# Assignment 4: Weather Dashboard using API

## Problem Statement
Develop a weather application displaying Temperature, Humidity, Wind Speed, Weather Icon, and Sunrise & Sunset time using OpenWeatherMap API with async/await and useEffect.

## Features
- **Search by City**: Search any global city with immediate API response.
- **Loading Spinner**: Interactive animated spinner state while fetching API data.
- **Error Handling**: Graceful error handling for invalid cities or network failures.
- **Metrics Display**: Temperature (°C/°F toggle), Humidity, Wind Speed, Sunrise, Sunset, Pressure, Visibility.
- **5-Day Forecast**: Multi-day outlook with weather icons.
