# Assignment 5: Online Shopping Cart

## Problem Statement
Create an online shopping cart using `useReducer` and `Context API`.

## Features
- **Product List**: Filterable catalog of products with ratings and prices
- **Add to Cart**: Dispatch action to append item or increase quantity
- **Remove Item**: Remove single item from cart state
- **Quantity Update**: Increment/decrement or set custom quantity
- **Coupon Code**: Percentage discount code facility (`SAVE10`, `DISCOUNT20`, `MEGA50`)
- **GST Calculation**: Itemized 18% GST calculation + Grand Total display
