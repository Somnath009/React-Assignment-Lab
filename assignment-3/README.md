# Assignment 3: Employee Directory using State and Events

## Problem Statement
Employee data of a farm/company is maintained with Name, Employee ID, Department Name, Gender, Phone Number, Local address, and Permanent address.

## Features
- **Add Employee**: Modal form with field validations
- **Delete Employee**: Instant delete action with prompt confirmation
- **Edit Employee details**: Pre-filled form update handler
- **Search Employee**: Realtime search by Name, ID, or Phone
- **Employee Count**: Stat counter widgets (Total, Engineering, Operations, HR)
- **Department Filter**: Clickable filter chips by department
