# Assignment 2: Student Information Management using Props

## Problem Statement
Create a student information portal. Each student card displays Name / Roll Number / Department / Semester / CGPA / Photo.

## Required Components
- `App` (`Assignment2App.jsx`)
- `StudentList` (`StudentList.jsx`)
- `StudentCard` (`StudentCard.jsx`)
- `Header` (`Header.jsx`)
- `Footer` (`Footer.jsx`)

## Key Features
- All data passed down through React Props.
- CGPA sorting mechanism (High to Low / Low to High).
- Department filter and real-time name/roll search.
